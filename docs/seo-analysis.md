## 対応方針（優先順）

1. **サイトマップを再送信する**: Search Console から同じ URL を再送信する（2026-10-20 実施済み。処理結果は後日確認）
2. **title・description を見直す**: 用途（Slack・Discord）、無料、PNG・GIF 対応が伝わる文言にする。OGP・Twitter Card・JSON-LD の説明文も揃える
   - title 案: `emoemo - Slack・Discordの絵文字を無料作成｜PNG・GIF対応`
   - description 案: `好きな文字から、Slack・Discord用のカスタム絵文字を無料で作成。登録不要で、ブラウザから128×128pxの透過PNGやアニメーションGIFをダウンロードできます。`
3. **短い説明本文を足す**: 作れるもの、使い方3ステップ、Slack・Discord への登録方法。画像寸法（128×128px）とファイル容量（KB）は分けて書き、各サービスの条件は公式ヘルプを確認してから書く
4. **外部での紹介**: GIF デモ付きの開発記事（Zenn など）、GitHub リポジトリの About・topics の設定。参照元ページが 0 件なので、ここを増やす
5. **速度**: 実データがないため、PageSpeed Insights などで計測してから判断する

## やらないこと

- FAQPage の構造化データ: Google は 2026-05-07 で FAQ リッチリザルトの表示を終了している
